# 0007 — Dados estruturados em SQL; RAG só no texto dos anexos

- Status: aceita (12/10/2026)

## Decisão

Preço, quantidade, data, órgão, fornecedor e vigência são respondidos por SQL parametrizado.
Busca semântica/híbrida só para o texto de TR, ETP e edital.

## Consequências

- Respostas numéricas exatas e reprodutíveis.
- O RAG pode ser adiado para a Fase 5 sem bloquear o valor das fases anteriores.
